# VarioSmooth

Lightweight, solar powered, helmet embedded audio variometer for free flight.

- [**v1**](v1/README.md) (2017): PIC24F16KA101 + MS5611, LTC4071 solar charger, 22 × 17 mm PCB. Firmware (MPLAB X / XC16), PCB (Eagle, ported to KiCad 10), docs and open issues.
- [**v2**](v2/README.md) (in progress): nRF52840 (Raytac MDBT50Q) with Bluetooth LE, sends barometric altitude and vario to XCTrack / LK8000. Firmware with PlatformIO, flex PCB.
